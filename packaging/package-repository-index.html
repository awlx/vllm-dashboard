vllm-dashboard Package Repository

Debian and Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://awlx.github.io/vllm-dashboard/vllm-dashboard.gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/vllm-dashboard.gpg
echo "deb [signed-by=/etc/apt/keyrings/vllm-dashboard.gpg] https://awlx.github.io/vllm-dashboard stable main" | sudo tee /etc/apt/sources.list.d/vllm-dashboard.list
sudo apt update
sudo apt install vllm-dashboard

Source and documentation: github.com/awlx/vllm-dashboard
